# 活动配队说法的可复现实验（2026-10-05）

本报告检验“3SSR+2R 或 2SSR+3R 拿 B 加成最高”“跳过一定亏 PT”“1SSR+活动 SR+3R 蓝曲可拿 B”“蓝谱低约 20%”四条说法。这里的“蓝曲”指歌曲的绀碧属性；“蓝谱”指 EASY 难度，两者不是一回事。数据为 2026-10-01 日服快照及单独补入的成员 #64，活动固定为 #1。卡库和养成均是**人工设定的实验条件，不是用户实际卡库**。

## 方法

脚本 [event_claim_experiments.py](../tools/event_claim_experiments.py) 对五种固定成员组合，使用相同的五张留影 #52/#61/#62/#63/#64，逐一搜索留影绑定与队长，目标是单场活动 PT。挑战曲 #100056、#100063、#100109 均以 200 CP、理论 AP 计算；分数取 120 种技能发动顺序中的最低值。成员技能 Lv5、角色 Rank 5、设施采用样本档案（最高 Lv3）。养成 0 档为各卡未觉醒上限，1 档为觉醒／特训／突破 1 次后的上限。完整输入 ID、得分、评级、加成、PT 与徽章在 [JSON 结果](../work/event-claim-experiments.json)。运行环境安装项目依赖后可执行：

```sh
PYTHONPATH=workbench:workbench/runtime python3 -B tools/event_claim_experiments.py
```

## 结果

三首挑战曲在养成 0 档的评级和 PT 相同。下表用 #100109 Expert 展示，两档均按该组合内 PT 最优绑定计算：

| 成员组合 | 养成 0 档 | 每局 PT | 养成 1 档 | 每局 PT |
| --- | ---: | ---: | ---: | ---: |
| 3SSR+2R | B，+180% | 7,140 | A，+210% | 10,075 |
| 2SSR+3R | B，+190% | 7,395 | B，+221% | 8,185 |
| 1SSR+活动 SR+3R | B，+175% | 7,012 | B，+203.5% | 7,739 |
| 2SSR+活动 SR+2R | B，+215% | **8,032** | A，+250.5% | **11,391** |
| 5R | C，+110% | 4,200 | C，+127% | 4,540 |

**“3SSR+2R 或 2SSR+3R 加成最高”不是通用结论。** 在这组共同留影、已获得活动 SR 的合成卡库里，2SSR+活动 SR+2R 的五名成员均为梦限大MewType，养成 0 档同样拿 B，却比 2SSR+3R 多 637 PT／局。养成 1 档它拿 A，差距更大。这只证明原说法不能普遍成立，不证明这五张卡在真实用户卡库里最优。

**“挑战曲满足 B 后越高加成越好”有条件成立。** 同一歌曲、同一 CP、同一评级下，活动 PT 基础值相同，加成更高不会减少 PT；但升到 A 可以抵消较低加成。例：养成 1 档 #100109 的 3SSR+2R 仅 +210%，A 评级得 10,075 PT；2SSR+3R 有 +221% 但只拿 B，得 8,185 PT。#100063 的后者又能拿 A，得 10,432 PT；所以须按目标歌曲逐局比较。

**“1SSR+活动 SR+3R 可以拿 B”在实验条件下成立。** 它在三首绀碧属性的梦限大挑战曲均达到 B，包括 #100109，养成 0 档得 7,012 PT，养成 1 档得 7,739 PT。这不保证别人的卡牌等级、技能、留影和设施也能达到 B。

**普通演出跳过固定 C，但“任何歌曲都不要跳过，否则 PT 一定亏”不成立。** [游戏内帮助](../workbench/runtime/research/2026-10-01/raw/MasterText.json) 的 `Help_SubCategory_Description_100002` 写明普通跳过按 C 评级奖励结算，不更新最高分。固定低练度合成队伍、普通 #100001 Expert、4 Boost：理论 AP 仅 D／510 PT／684 徽章／60 CP，跳过 C／850 PT／1,140 徽章／80 CP。另一支高练度队伍、普通 #100109 Expert、4 Boost：理论 AP 达 B／2,453 PT／2,851 徽章／100 CP，跳过 C／1,752 PT／2,037 徽章／80 CP。跳过对累计奖励是否吃亏取决于手打能达到的评级，以及能否实际打完；它仍受游戏规定的每日次数限制。挑战演出没有跳过。

**“蓝谱低 20%”是近似现象，不是固定倍率。** 保持同一队伍、留影绑定、队长与歌曲，比较三首曲、三种队伍共 9 组：EASY 相对 EXPERT 低 **18.38%–20.98%**；相对 NORMAL/HARD/EXPERT 三者均值低 **14.36%–16.74%**。NORMAL 相对 EXPERT 低 8.45%–11.48%，HARD 低 2.22%–5.82%。例如 #100109 的 3SSR+2R 养成 0 档为 EASY 3,337,960、NORMAL 3,666,428、HARD 4,013,678、EXPERT 4,104,820。比较基准、谱面、队伍技能与发技时间不同，百分比就会变；这些是模型 AP 分数，并非实机全 PC 观测。

## 结论的边界

公开活动页列出普通与挑战各评级的 PT／徽章基础值；客户端帮助给出跳过的固定 C 规则。当前实验验证的是实现与这两类已知规则及人工卡库下的比较结果。没有用户的 P1/P2 图片或本轮实机结算，无法验证原帖所用具体卡库、养成、全 PC 表现，也无法把所有模拟结果保证为服务器实结。用于活动 SR 满破拉表时，应以单场 **PT** 为目标；徽章用于交换所，使用留影加成单独计算。挑战门票凹榜分时选择分数目标，刷累计奖励时选择单场 PT 目标；若两者需要兼顾，先确定累计 PT 目标所需门票，再比较剩余门票的分数队。
