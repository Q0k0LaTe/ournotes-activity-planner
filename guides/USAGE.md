# 使用说明 · v0.3.0

当前数据以 2026-10-01 日服快照及活动 1 为基准，成员卡 #64 已单独补入。活动配队是默认目标；后续还有歌曲模拟和活动拉表。

1. 在“我的卡牌”的完整图鉴中添加已拥有成员和留影，填写实际等级、特训、觉醒、Live 技能与突破。图鉴默认显示全部卡牌；“已拥有”只显示你已录入的卡。勾选参与配队的卡。卡库里的搜索筛选用于整理；配队配置里的筛选才限制计算候选。
2. 在“道具与角色”填写角色等级、总等级、TGW 等级与道具等级。不要把未知养成当满级；“检查所需养成”可定位缺项。
3. 在“活动配队”选择目标、普通／挑战场景与结果数。默认先最大化活动 PT 加成，不要求指定歌曲。可组合成员／留影属性、最低稀有度、乐队和角色范围。多个范围之间取交集；空范围表示不限。
4. 必带槽位中空位由算法补齐；同角色只允许一名成员。指定队长会加入必带；固定留影绑定也会强制对应成员与留影入队。加成底线填写百分比，如 `100` 表示至少 +100%。不满足条件时会返回无可行队伍。
5. 开始计算。最多 15 套不同成员集合＋留影集合；相同集合的不同摆位不占多个名额。取消后不展示不完整列表，再次用相同条件计算可复用已证明的队伍。关闭／刷新网页会结束当前计算，完整候选已存到浏览器后可续算。
6. 在结果中比较最多三套，查看每张成员绑定的留影、有效技能与队长，复制参数、保存图片或导出 JSON。转到“歌曲模拟”验算所选队伍；指定歌曲、难度、打法与消耗后，可从候选卡池分别搜索单场 PT、活动徽章或理论分数最高的队伍。普通演出刷累计奖励选 PT，挑战门票凹榜分选理论分数；用于刷 PT 或活动徽章的挑战场次也按实际目标搜索。
7. 配队完成后，点“用配队结果拉表”：普通与挑战可分别选队伍、奖励评级及 Boost／CP 档位，无需指定歌曲即可从活动 #1 的基础奖励和队伍加成估算每局 PT、CP、徽章，再生成每日场次与 CSV。普通跳过固定按 C 结算。预设 B 只是评级假设，配队结果不能保证拿到 B；有实机结算或歌曲模拟值时，请在拉表页直接改为实际单场收益。默认 PT 目标 675,000，对应活动 #1 的第五张活动 SR。

“多方向配队”依次寻找技能覆盖、综合潜力、基础力权重较高、活动加成、徽章加成方向的不同卡组。单一方向才表示该指标下的前若干不同集合。活动 PT／徽章目标先最大化对应加成，再用综合潜力打破并列；加成本身不是最终收益。

“指定队伍”直接检查五名成员、五张绑定留影与指定／自动队长，不遍历卡库，也不受推荐筛选和加成底线影响。显示位置表示绑定关系，不表示技能发动顺序。

“档案与说明”可以复制当前卡库为升级规划、切换档案、备份全部档案。示例是合成养成，不代表账号。旧网站卡库会自动迁移；也可导入旧卡库 JSON，歌曲条件将被忽略。卡库只保存在当前网址和浏览器，多个标签页同时修改时旧页变为只读，先导出再刷新。

不指定歌曲的潜力指标假设每名成员发动一次技能且音符均匀分布，不含技能截断、连击权重、谱面密度及乐曲标签，不能当具体歌曲分数。歌曲模拟使用固定快照的谱面与得分模型；理论 AP 比较 120 种技能顺序的最低分。普通跳过固定按 C 评级奖励结算，页面上的跳过参考分数不参与 PT／徽章／CP，也不更新最高分；挑战演出不能跳过。活动拉表按固定每局收益计算，不自动计入累计 PT 奖励中的额外徽章。撃奏、协力、新活动未建模。快照后仅补入成员卡 #64，其余新卡暂时无法录入。验证范围见 [活动计算验证](EVENT-VALIDATION.md)及[玩家说法验证](CLAIM-EXPERIMENTS.md)。
