默认按活动 PT 加成配队，同评级下代表每局 PT 更多；普通跳过固定按 C 评级奖励结算，模型参考分不计最高分。徽章加成独立计算。最多 15 套不同成员卡与留影集合；潜力是均匀覆盖参考指标，不代表具体谱面分数。

歌曲模拟可验算推荐队伍，也可针对一首歌分别搜索每局活动 PT、活动徽章或理论分数最高的队伍。普通演出不计活动参数加成，挑战演出计入。活动拉表使用模拟值或游戏实测的每局收益计算普通 → CP → 挑战场数。

卡库和结果自动保存在本地浏览器；可创建多个档案，并导入或导出 JSON 备份。换浏览器或清理网站数据前请备份。数据不会自动更新。
